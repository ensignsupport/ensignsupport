  - Question 1: **Who is this for?**

## Copy notes for design

- Every heading answers one visitor question from the page question maps.
- Words per screen stay low. If a design needs fewer words, cut, don't shrink text.
- One negation reframe per page at most: Home uses none. Services uses none. About uses none. Contact uses "Ensign is not a crisis service" (crisis box).
- Hand-made marks: underline on Home headline, brush stroke portrait frames, Andrew's signature.
