Evidence behind this shortlist
  • Local competitors all use free, common fonts: Poppins, Lato, Quicksand, Nunito (measured on their live sites).
  • The best sites use professional foundry fonts: Mosh uses Clearface with Maison Neue. Leap in! uses Founders Grotesk (Klim). Hireup uses Inter with a display font, New Burns. Your Mighty Moose site uses Bricolage Grotesque, Source Sans 3 and a handwritten accent (Caveat).
  • Premium mental health and wellbeing brands (Fonts In Use) keep pairing a warm serif with a clean sans: Likeminded (ITC Souvenir + Aeonik), Oltre (Hedvig Letters Serif + Sans), Care/of (Lora + F37 Ginger).
  • So every option here follows that proven pattern, using fonts that are free for commercial use and rarely seen on AI-made sites.
Round 2: professional foundry fonts (needs you)
  • Paid foundries give free trial fonts for mockups and client presentations, but not for the live site. I cannot sign up and download them for you.
  • Shortlist to trial: Tiempos Headline + Söhne (Klim, klim.co.nz/test-fonts). GT Alpina + GT America (Grilli Type). Aeonik + a warm serif (CoType Foundry).
  • If you have Adobe Creative Cloud: Adobe Fonts are licensed for websites. Send me the web project kit and I add those too.
  • Download the trial files into the ensign folder and I build them into this same test. We buy a licence only for the winner.
Signature idea
  • Instead of a script font, use Andrew's real signature: he signs a white page, you photo it, I turn it into a clean vector. Truly his, no licence, impossible for anyone to copy.
Reveal the font names (after you pick)
  • Option 1: Hedvig Letters Serif + Hedvig Letters Sans. Google Fonts (Kanon Foundry). Free, commercial use allowed. A matched serif and sans family designed together. Warm, slightly old-world letters. Rare on AI sites.
  • Option 2: Gambarino + Switzer. Fontshare (Indian Type Foundry). Free, commercial use allowed. Soft, rounded serif headings with a crisp Swiss-style body. Similar mood to premium health brands (warm serif plus clean grotesk).
  • Option 3: Literata + Atkinson Hyperlegible Next. Google Fonts (TypeTogether, Braille Institute). Free. Last round's option A, kept as a control.
  • Option 4: Bricolage Grotesque + Atkinson Hyperlegible Next. Google Fonts. Free. Last round's option B, kept as a control. Also the heading font on Mighty Moose Mowing.
  • Option 5: Erode + Atkinson Hyperlegible Next. Fontshare (Indian Type Foundry) + Google Fonts. Free. A confident, sharper serif for headings with the most readable body font available.
  • Option 6: Mogilte headings + Century Gothic for everything else, as in your reference. Mogilte by Storytype Studio (paid licence, Creative Market or Creative Fabrica). Century Gothic by Monotype (paid web licence, MyFonts). If either is installed on your Mac, your browser shows the real font. Otherwise you see free stand-ins: Gloock for Mogilte, Didact Gothic for Century Gothic.
  • Option 7: Same as 6, but body text in Atkinson Hyperlegible Next for readability. Century Gothic kept for small labels and buttons.
  • Option 8: Metamorphous headings + Cantarell body. Both free on Google Fonts (Open Font Licence), commercial use allowed. Metamorphous by Sorkin Type, Cantarell by Dave Crossland for the GNOME desktop.
  • Option 9: Young Serif + Hanken Grotesk. Google Fonts, free, commercial use allowed. Friendly, warm, chunky.
  • Option 10: Boska + Switzer. Fontshare (Indian Type Foundry), free, commercial use allowed. Elegant, magazine-like.
  • Option 11: Source Serif 4 + Source Sans 3. Adobe open source, free on Google Fonts. Calm, professional, very readable.
